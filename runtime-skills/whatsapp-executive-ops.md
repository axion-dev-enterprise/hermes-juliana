# WhatsApp Executive Communication Skill
# VERSIÓN: V6.1.0 • HERMES CENTRAL JULIANA

## 1. OBJETIVO
Procedimento para disparo e gerenciamento de mensagens via Baileys WhatsApp Keeper com o prefixo oficial do Hermes Agent (`⚕ *Hermes Agent*\n────────────\n`).

## 2. REGRAS DE COMUNICAÇÃO
- Utilizar sintaxe nativa WhatsApp (*negrito*, _itálico_).
- Não utilizar marcadores Markdown complexos (tabelas, headers com #).
- Garantir tom executivo, acolhedor e focado na resolução.

## 3. FERRAMENTAS
- `SEND_WHATSAPP_MESSAGE`: Dispara mensagem direta via Baileys Keeper.
